# Open-source and model license inventory

The application and synthetic data are Apache-2.0. No paid API, proprietary cloud AI or hosted service is required by the demo. Libraries were chosen for established open-source licensing; optional open-weight models are separately licensed and are never bundled.

Exact installed versions and declared licenses are recorded in [dependency-inventory.json](dependency-inventory.json), generated by `python scripts/licenses.py`. It includes runtime and development packages. `requirements.txt`, `requirements-dev.txt` and `apps/web/pnpm-lock.yaml` lock versions. This inventory is not a substitute for retaining the license/notice files when redistributing dependencies or container images.

## Model replacement policy

Only configure lawfully obtained local weights. Document model name, immutable digest, quantization, model-card URL and license before publishing a new benchmark. “Open weights” does not automatically mean OSI-open-source software or unrestricted use; review each model's actual terms. The default Qwen3 examples have a well-understood Apache-2.0 declaration. No model weights, private dataset, customer data or credentials are committed.
