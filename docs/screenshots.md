# Screenshots

These images are captured from the real running application, not design mockups:

- `images/overview.png`: first viewport, used as the README cover.
- `images/portfolio.png`: portfolio, timeline, family exposure and all markets.
- `images/market-evidence.png`: Austin material gates, source IDs and ledger.
- `images/scenario.png`: delayed-PO / accelerated-build comparison.
- `images/mobile.png`: responsive 390-pixel layout.

Start the API and frontend, then from `apps/web`:

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```

Default viewport: 1440 × 1180, with a full-page portfolio capture. The mobile case uses 390 × 844. The scenario and invalid import generated by this suite are persisted in its test/demo database; use a disposable store when recapturing. Screenshot files are overwritten intentionally.

For a manual portfolio screenshot, open the app at the same viewport, wait for charts and market rows, and capture the full page. Do not replace actual computed values or hide failure states when publishing evidence.
