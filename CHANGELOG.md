# Changelog

## 0.1.0 — local release candidate

- Added a deterministic material planning core with readiness, dated constraints, binding phase paths and conservative supply handling.
- Added immutable scenarios, guarded transfer recommendations and diagnostic consumption forecasting.
- Added schema-validated imports, visible validation reports, transactional persistence and a versioned API with offline documentation.
- Added a responsive analytical workspace, evidence drill-downs, exports and provenance inspection.
- Added optional local Ollama evidence selection, abstention, fallback and observable telemetry.
- Added synthetic data, automated tests, real screenshots, measured benchmarks, Docker Compose and GitHub workflow definitions.
- Container/PostgreSQL execution and hosted CI are explicit outstanding release gates; see `docs/release-checklist.md`.
